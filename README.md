# PROJECT 11122 v3.0 FINAL

## 핵심 추가 기능

### 1. 확정 학교 시간표
월요일부터 금요일 1~7교시를 전 과목 풀네임으로 반영했습니다.

자습 가능 18교시:
- 전자기기 가능 15교시
- 전자기기 불가 3교시

전자기기 불가 자습은 생명과학Ⅱ 시간입니다.

### 2. 인강 자판기
현재 확정된 모든 인강을 강의별로 낱개 표시합니다.

- 김승리 All Of KICE Origin 1~14강
- 김승리 All Of KICE Predator 독서 1~32강
- 김승리 All Of KICE Predator 문학 1~38강
- 김승리 All Of KICE Predator 독서 W.O.W 1~56강
- 우영호 LEAD IN 1~29강
- 우영호 CORE 1~7강
- 임정환 LIM IT 1~30강

강의를 클릭해 장바구니에 담고 날짜를 선택한 뒤 `오늘 일정 만들기`를 누르면:

수학처럼 아직 세부 강좌가 확정되지 않은 경우 `+ 사용자 강좌 추가`에서 과목·강좌명·전체 강의 수를 입력하면 앱 업데이트 없이 1강부터 자동 생성됩니다.


- 오늘 할 일에 강좌별로 묶어서 추가
- 학교가 있는 날은 전자기기 가능한 자습 교시에 한 강씩 우선 배치
- 수강 완료 체크 시 강좌 진도 자동 반영

### 3. 9모 완주 압력
남은 인강 수와 9모 전 남은 집중 학습일을 이용해 `하루 몇 강이 필요한지`를 매일 계산합니다.
설정 화면의 `하루 인강 계획 상한`과 비교해 가능 / 빡빡 / 위험을 표시합니다.

- 수면·피로·두통·집중력·카페인·비타민
- 최소 성공선
- 오늘 마감
- 실모·기출 점수/등급
- 11122 도달 상태
- 9모 역산 진도 지도
- 수정안 미리보기와 최근 5회 되돌리기

- 일요일 등산·회복
