## v6.9 핵심

### 날짜별 시간표 예외 처리
- 평일 고정 블록도 특정 날짜에 한해서 삭제할 수 있습니다.
- 고정 블록 삭제는 기본 주간 시간표를 건드리지 않고 해당 날짜에만 숨김 처리됩니다.
- 삭제한 고정 블록은 `삭제 블록 복원`으로 다시 살릴 수 있습니다.
- 삭제된 블록에 연결돼 있던 오늘 할 일은 삭제되지 않으며 시간표 배정만 사라집니다.

### 날짜별 시간표 유형
시간표에서 날짜마다 다음 구조를 선택할 수 있습니다.
- 평일 기본
- 토요일 시종
- 학교 없음
- 저장 시간표

`토요일 시종`은 08:40~17:00의 6개 토요일 블록을 사용합니다. `학교 없음`은 고정 블록이 없는 빈 날짜에서 필요한 블록만 직접 추가할 수 있습니다.

### 저장 시간표
- 현재 날짜의 시간표를 이름 붙여 템플릿으로 저장할 수 있습니다.
- 저장 시간표를 다른 날짜에 다시 적용할 수 있습니다.
- 이름 변경, 현재 시간표로 덮어쓰기, 복제, 삭제를 지원합니다.
- 적용은 선택한 날짜에만 영향을 주며 기본 월~금 시간표나 다른 날짜를 바꾸지 않습니다.
- 저장 시간표를 적용하거나 시간표 유형을 바꿔도 오늘 할 일 데이터는 유지됩니다.
