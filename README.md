# PROJECT 11122 v6.8 · STABILITY EDITION

9모 11122 → 수능 11111 학습 운영 PWA.

## v6.8 핵심

### 자동화 안정화
- 미래 날짜 열람과 자동화 실행을 분리했습니다. 미래 날짜는 예정만 보여주며 할 일/충돌을 생성하지 않습니다.
- 자동화 실행키를 저장해 새로고침·재진입에도 같은 날짜의 할 일이 중복 생성되지 않습니다.
- 대기함의 미완료 인강/소단원도 중복 검사에 포함합니다.
- `오늘 것과 합치기`가 이전 미완료 + 오늘 예정분을 실제 하나의 묶음으로 병합합니다.
- 자동화 규칙 수정 시 오래된 충돌/실행기록을 정리하고, 이미 생성된 미완료 항목 처리 여부를 확인합니다.
- `오늘만 건너뛰기`는 실제 오늘에만 적용됩니다.

### 시간표·학습량
- 월~금 전체 고정 시간표를 한 화면에서 보는 `주간` 탭을 복구했습니다.
- 시간표 체크와 할 일 체크는 완료 상태가 독립적이며, 배정 연결만 유지합니다.
- 인강 1~3강은 홈뿐 아니라 월간·분석·일일기록에서도 3개 단위로 집계합니다.
- 직접 시간 블록 저장 시 겹침을 경고하고 잘못된 시각을 차단합니다.

### 수면·날짜
- D일 수면은 D-1일 밤 취침 + D일 아침 기상으로 통일했습니다.
- 월말·연말·자정 경계 로직을 회귀 테스트에 포함했습니다.

### 데이터·코드 안정성
- 데이터 스키마 8과 명시적 마이그레이션을 도입했습니다. 기존 저장소 `p11122_v60_db`를 그대로 사용합니다.
- 마이그레이션 전/백업 복원 전 안전 스냅샷을 남깁니다.
- 저장 실패 감지, 저장 용량 표시, undo 스냅샷 축소를 적용했습니다.
- 진단 기능을 중복/끊어진 연결/시간 겹침/자동화/수면 동기화/저장 용량까지 확장했습니다.
- 누적 CSS 중복 규칙을 정리하고 v6.8 최종 규칙으로 통합했습니다.

### iPad 분할화면
- 980px 이하에서 상단 메뉴가 터치하기 쉬운 가로 스크롤 탭으로 전환됩니다.
- 학습 자판기, 시간표, 주간표, 모달이 좁은 화면에서 본문 밖으로 잘리지 않도록 반응형 레이아웃을 적용했습니다.

## 검증
`tests-v68.js`에서 자동화 중복/미래 날짜/대기함/병합/체크 독립/수면 날짜/강의 단위/시간 겹침/마이그레이션/백업을 검사합니다.

브라우저 레이아웃 QA는 1365×900, 1024×768, 600×820, 390×844에서 수행했습니다. 문서 전체의 가로 overflow 없이 렌더링되며, 600px 분할화면에서 학습 자판기·주간·시간표 화면을 별도로 확인했습니다.

## 데이터 호환
기존 `p11122_v60_db`를 유지합니다. v6.8 첫 로드에서 기존 데이터는 schema 8로 자동 보완됩니다.
