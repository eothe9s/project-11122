## 핵심 구조
학습 자판기 → 자동화 → 오늘 할 일 → 시간표 배정 → 완료 → 강좌 진도 → 월간/시험 분석

## 주요 기능
- 월간 달력: 날짜별 달성률·실제 순공시간·시험 표시
- 05:00~다음 날 01:00 텐미닛 시간표
- 보기 모드 / 편집 모드 분리
- 10분 칸 클릭-클릭 또는 드래그로 시간 블록 생성
- 시간 블록 생성·수정 시 실제 시작 시각 기준 자동 정렬
- 과목 색상
  - 수학 연파랑
  - 국어 연노랑
  - 영어 연한 빨강
  - 사회문화 연한 초록
  - 경제 연한 보라
- 시간표 '할 일 선택'은 직접 타이핑이 아니라 그 날짜의 할 일 목록에서 선택
- 시간표 ↔ 할 일 완료 양방향 동기화
- 한 블록에 여러 할 일 / 한 할 일을 여러 블록에 배정 가능
- 묶음 과제 부분 완료
- 문제집 01·02·03 연속 선택 → 01~03 자동 묶음
- 학습 자판기와 강좌 진도 완전 연동
- 반복 자동화: 요일 지정 / 오늘만 건너뛰기 / 일시정지 / 미완료 충돌 처리
- 이번 주 대기함
- 오늘 계획 확정·잠금 + 과부하 검사
- '지금 할 것' 실행 모드
- 계획 자습 / 자동 실제 / 최종 순공시간 분리
- 최종 순공시간 수동 보정 + 자동값으로 복귀
- 최근 학습 공백
- 실모·성적 + 오답 원인 누적
- 과목별 시험 + 전과목 모의고사 기록
- 9모 → 수능 자동 단계 전환
- 수면·컨디션 기록
- 최근 7일 및 월간 분석
- 데이터 검사
- 7일 휴지통
- 최근 5회 변경 되돌리기
- JSON 백업·복원
- 기존 v2~v5 localStorage 기록 자동 마이그레이션
