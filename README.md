## 적용 순서
1. 업데이트 전에 현재 앱의 백업 버튼으로 JSON 백업을 저장합니다.
2. ZIP을 압축 해제합니다.
3. GitHub 저장소 → Add file → Upload files에서 위 파일을 모두 업로드합니다.
4. Commit changes를 누릅니다.
5. 1~3분 뒤 앱을 완전히 종료하고 다시 엽니다.
6. 구버전이면 사이트 주소 끝에 `?v=2`를 붙여 한 번 엽니다.
