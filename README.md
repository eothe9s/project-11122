# PROJECT 11122 v5.0 COMPLETE

이번 버전은 v4.1의 기존 기능을 보존하면서 사용성 개선 요구사항을 통합한 최종본입니다.

핵심:
- 시간표의 `할 일 선택`은 오늘 할 일 목록에서 다중 선택
- 시간표 완료 ↔ 할 일 완료 양방향 동기화
- 한 블록에 여러 할 일 / 한 할 일을 여러 블록에 배정
- 묶음 인강·문제집 부분 완료
- 문제집 연속 항목 자동 묶음
- 학습 자판기와 강좌 진도 단일 원본 연동
- 기본 고정 오르새 수학 / 영어 일일 루틴 / 사문 실모 진도 항목 제거
- 반복 자동화: 요일 지정, 오늘만 건너뛰기, 일시정지, 미완료 충돌 처리
- 이번 주 대기함
- 오늘 계획 확정/잠금
- 학습 자판기 빠른 검색 및 최근 사용
- 최근 7일 최소 통계
- 설정·백업은 우측 하단 톱니바퀴

자동화는 시간표에 강제로 꽂지 않고 할 일 목록까지만 생성합니다.

추가 사용성:
- 문제집 소단원은 버튼을 연속 클릭해 장바구니에 바로 담을 수 있습니다. 01·02·03은 일정 생성 시 01~03으로 자동 묶입니다.
- 시간표 할 일 선택은 오늘 할 일 목록의 체크 방식이며 여러 개 동시 배정이 가능합니다.
