# PROJECT 11122 v2.4 FINAL GUARD

## 추가된 핵심 기능

1. 수정안 미리보기
   - ChatGPT 수정 코드를 붙여넣어도 바로 덮어쓰지 않습니다.
   - 적용 전 과제 수, 목표 순공시간, 시간표 변경을 비교합니다.

2. 최근 5회 되돌리기
   - 수정안을 적용하기 직전 상태를 자동 저장합니다.
   - 계획 검증·보고 화면에서 날짜별로 되돌릴 수 있습니다.

3. 오늘 최소 성공선
   - 우선순위가 `필수`인 과제만 별도 표시합니다.
   - 필수 과제를 모두 끝내면 최소 성공선 달성으로 표시됩니다.

4. 9모 역산 진도 지도
   - 2026년 9월 2일을 기준으로 네 구간을 보여줍니다.
   - 강좌 진도 탭에서 설정한 목표 완료일도 해당 구간에 표시합니다.

5. 오늘 마감
   - 과제 체크
   - 순공시간·저녁 컨디션·카페인 기록
   - 선택적 실모 점수 입력
   - 일일 보고서 복사
   순서로 1분 안에 마칠 수 있습니다.

## 업데이트

1. 현재 앱에서 `설정·백업 → 전체 기록 내보내기`
2. ZIP 압축 해제
3. GitHub 저장소 → `Add file → Upload files`
4. 압축을 푼 파일 전부 업로드
5. `Commit changes`
6. 1~3분 뒤 홈 화면 앱을 완전히 종료하고 다시 실행
7. 구버전이면 주소 끝에 `?v=24`를 붙여 한 번 접속

기존 v2.x 저장 키를 그대로 사용하므로 같은 GitHub Pages 주소에서 업데이트하면 기록이 유지됩니다.
